# Changelog / Catatan perubahan

## English — 1.0.0

- Community name becomes **Barnyard Linux**, replacing user-facing test labels.
- New Barnyard/Linux fan application icon; original in-game title art unchanged.
- Native X11 window identity and diagnostic icon match the desktop launcher.
- APT replaces the old test package; legacy save/config directories are retained.
- Existing FPS toggle, fullscreen, text-language settings, About credits and
  explicit-click external links are preserved. No FPS cap/VSync change.
- Added publication-ready English/Indonesian documentation and two user gameplay
  screenshots; public distribution has not been performed by this preparation.

Earlier milestones introduced native graphics/input/media/save support, direct
launch, persistent options, draft Indonesian text, About and an optional FPS
counter. Version 1.0.0 is not a claim of universal hardware/gameplay certification.

## Bahasa Indonesia — 1.0.0

- Nama komunitas menjadi **Barnyard Linux**, tanpa label test di tampilan aplikasi.
- Ikon fan-made Barnyard/Linux baru; logo judul asli di dalam game tidak diubah.
- Identitas jendela X11 dan ikon diagnostik sesuai launcher desktop.
- APT mengganti paket test lama; folder internal save/config dipertahankan.
- Toggle FPS, fullscreen, bahasa, kredit About, dan tautan eksternal hanya-klik
  tetap ada. Tidak ada perubahan pembatas FPS/VSync.
- Dokumentasi Inggris/Indonesia dan dua screenshot pengguna disiapkan untuk
  publikasi; persiapan ini belum mengunggahnya ke repo publik.

Tahap sebelumnya menambahkan grafik/input/media/save native, peluncuran langsung,
opsi persisten, teks Indonesia draf, About, dan penghitung FPS opsional. Versi
1.0.0 bukan klaim sertifikasi semua perangkat atau seluruh alur permainan.
