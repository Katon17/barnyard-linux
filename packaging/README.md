# Packaging / Pengemasan

## English

Current package: `barnyard-linux_1.0.0_amd64.deb`. Runtime: i386, built on Noble.
`build-deb.sh` validates a runtime manifest, evidence and matching binary hash;
it must run in the matching Ubuntu 24.04 baseline. Packaging is not ordinary
installation. See ../docs/BUILD.md. Old preview/test scripts remain for history
and regression fixtures, not as the recommended current installer.

## Bahasa Indonesia

Paket terkini: `barnyard-linux_1.0.0_amd64.deb`. Runtime i386, dibangun di Noble.
`build-deb.sh` memvalidasi manifest, bukti, dan hash runtime; harus dijalankan di
basis Ubuntu 24.04 yang sesuai. Packaging berbeda dari instalasi biasa; lihat
