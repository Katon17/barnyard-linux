# Security and privacy / Keamanan dan privasi

## English

No formal support window, security audit or response-time guarantee is promised.
Do not run the game/launcher as root. Use owned data from a trusted local source.
Logs may include usernames and local paths; review before sharing.

For a sensitive vulnerability, use GitHub private vulnerability reporting **if
it has been enabled by the maintainer**. If unavailable, open a minimal issue
asking for a private contact channel without exploit details or secrets. Do not
post access tokens, personal saves, arbitrary file contents or retail assets.

Maintainers should enable GitHub private reporting and dependency alerts where
appropriate. Publishing this file does not itself enable those features.

## Bahasa Indonesia

Belum ada jaminan masa dukungan, audit keamanan, atau waktu respons. Jangan
jalankan game/launcher dengan root. Gunakan data milik sendiri dari sumber lokal
tepercaya. Log bisa memuat username/path; periksa sebelum dibagikan.

Untuk kerentanan sensitif, gunakan pelaporan privat GitHub **jika sudah diaktifkan
maintainer**. Jika belum tersedia, buat issue singkat meminta kanal kontak privat
tanpa detail eksploit atau rahasia. Jangan unggah token, save pribadi, isi file
sembarangan, atau aset retail.

Maintainer disarankan mengaktifkan pelaporan privat dan alert dependensi yang
sesuai. Berkas ini tidak otomatis mengaktifkan fitur tersebut.
