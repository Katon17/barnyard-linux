# Barnyard Linux 1.0.0 / Rilis 1.0.0

## English

Unofficial community native port by Katon Bagaskoro. New application name/icon;
original in-game art unchanged. Existing saves/preferences are retained, with
FPS toggle, fullscreen, draft Indonesian text and About credits preserved.

Install on Linux Mint 22.x / Ubuntu 24.04 amd64 with i386 enabled:

```bash
sudo apt install ./barnyard-linux_1.0.0_amd64.deb
```

Requires legally owned complete PC game data. No retail assets, Wine or Windows
DLLs included. User-reported smooth 60 FPS is not a benchmark or universal
certification. Upstream non-commercial terms apply; this binary is **not GPL**.
Review LICENSE.md, including donation-related distribution caveats. This release
is created as a **draft** in a **private** repository by the supplied helper.
